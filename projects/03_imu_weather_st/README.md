# 案例3: 桌面天气站/动态水平仪（未来目标）

## 实验目标
集成 MPU6050 陀螺仪和蓝牙模块，实现一个桌面天气站或动态水平仪应用，展示多模块协同工作能力。

## 功能规划
### 核心功能
1. **动态水平仪**
   - 实时显示设备倾斜角度
   - 气泡水平仪界面
   - 角度校准功能

2. **桌面天气站**
   - 显示温度、湿度（需额外传感器）
   - 时间日期显示
   - 蓝牙无线数据传输

3. **数据记录**
   - 运动数据记录到 SD 卡（可选）
   - 通过蓝牙传输到手机 App

## 硬件需求
| 模块 | 型号 | 接口 | 功能 |
|------|------|------|------|
| FPGA 主控 | Artix-7 XC7A100T | - | 系统控制 |
| 显示模块 | SPI TFT LCD | SPI | 图形界面显示 |
| 运动传感器 | MPU6050 | I2C | 倾角检测 |
| 无线模块 | HC-05 | UART | 蓝牙通信 |
| 温湿度传感器 | DHT11/DHT22 | 单总线 | 环境监测（可选） |
| 存储模块 | microSD 卡 | SPI | 数据记录（可选） |

## 软件架构
### 顶层模块
- `top_v3_imu_weather.v` - 系统顶层
- 集成显示控制器、IMU 驱动、蓝牙模块

### 数据处理流程
1. MPU6050 数据采集（加速度、角速度）
2. 姿态解算（互补滤波或卡尔曼滤波）
3. 图形界面渲染（水平仪、数据图表）
4. 蓝牙数据传输（JSON 格式）
5. 用户交互处理（按键、触摸）
