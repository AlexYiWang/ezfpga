# 案例1: 基础九宫格显示验证

## 实验目标
验证 SPI TFT LCD 屏幕的基本显示功能，通过九宫格颜色块测试屏幕驱动和颜色输出。

## 硬件连接
| FPGA 引脚 | LCD 模块信号 | 说明 |
|-----------|--------------|------|
| P1        | CS           | 片选，低有效 |
| P2        | DC           | 数据/命令选择 |
| P3        | RESET        | 复位，低有效 |
| P4        | SDA          | SPI 数据线 |
| P5        | SCL          | SPI 时钟线 |
| 3.3V      | VCC          | 电源 3.3V |
| GND       | GND          | 地 |

## 软件设计
- **顶层模块**: `top_v1_basic.v`
- **显示模式**: 固定颜色九宫格
- **刷新率**: 60Hz

## 文件说明
- `rtl/top_v1_basic.v` - 顶层粘合逻辑
- `constrs/pin_constraints.xdc` - 管脚约束文件

## 使用步骤
1. 将本目录中的 RTL 和约束文件添加到 Vivado 工程
2. 根据实际硬件调整管脚约束
3. 综合、实现、生成比特流
4. 下载到 FPGA 开发板
5. 观察 LCD 屏幕的九宫格显示

## 预期结果
屏幕被分为 3×3 的九宫格（240×240 分辨率，每格 80×80），每个格子显示不同的颜色：
- 左上: 红色
- 中上: 绿色
- 右上: 蓝色
- 左中: 绿色
- 中心: 蓝色
- 右中: 红色
- 左下: 蓝色
- 中下: 红色
- 右下: 绿色

## 调试笔记
- 如果屏幕无显示，检查 SPI 时钟频率是否在 LCD 模块支持范围内
- 颜色异常时检查 RGB565 数据格式是否正确
- 确保复位信号在初始化完成后保持高电平
