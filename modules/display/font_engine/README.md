# 字符渲染引擎与 ASCII 字库 ROM

## 功能描述
提供字符渲染功能，支持从字库 ROM 读取点阵数据并转换为屏幕像素数据，支持多种字体尺寸和字符集。

## 特性
- 可配置字体尺寸（8×8、8×16、16×16 等）
- 内置 ASCII 字库 ROM（可打印字符 32-126）
- 支持前景色和背景色设置
- 抗锯齿支持（可选）
- 多语言字符集扩展接口

## 接口说明
### 控制接口
- `char_code` - 字符编码（ASCII 或自定义）
- `char_x` - 字符左上角 X 坐标
- `char_y` - 字符左上角 Y 坐标
- `fg_color` - 前景色（RGB565）
- `bg_color` - 背景色（RGB565）
- `start` - 开始渲染脉冲
- `done` - 渲染完成标志

### 显存接口
- `pixel_x` - 像素 X 坐标
- `pixel_y` - 像素 Y 坐标
- `pixel_color` - 像素颜色输出
- `pixel_valid` - 像素数据有效

### 字库 ROM 接口
- `rom_addr` - 字库地址
- `rom_data` - 字库数据（点阵行）

## 字体格式
### 8×16 ASCII 字体
- 每个字符：8 像素宽 × 16 像素高
- 存储：每行 1 字节，共 16 字节/字符
- 字符集：ASCII 32-126（95 个字符）
- 总大小：1520 字节

### 16×16 扩展字体
- 每个字符：16 像素宽 × 16 像素高
- 存储：每行 2 字节，共 32 字节/字符
- 可用于中文、图标等

## 工作流程
1. 接收渲染请求（字符编码、位置、颜色）
2. 计算字库 ROM 地址偏移
3. 逐行读取点阵数据
4. 将点阵转换为像素颜色（1→前景色，0→背景色）
5. 输出像素数据到显存接口
6. 标记渲染完成

## 性能优化
- 流水线操作：字库读取与像素生成并行
- 批处理：支持连续字符渲染
- 缓存：常用字符点阵缓存（可选）

## 目录结构
- `rtl/` - RTL 源码
  - `font_engine.sv` - 主渲染引擎
  - `font_rom.sv` - 字库 ROM（可参数化）
  - `char_renderer.sv` - 字符渲染器
- `tb/` - 测试平台
- `fonts/` - 字库数据文件
- `tools/` - 字库生成脚本
