# AXI4-Lite 通用控制器接口

## 功能描述
提供标准的 AXI4-Lite Slave 接口，用于将 FPGA 外设接入基于 AXI 总线的 SoC 系统（如 MicroBlaze、Zynq PS 等）。

## 特性
- 符合 AXI4-Lite 协议规范
- 可配置数据宽度（32 位）
- 支持读写响应（OKAY、DECERR、SLVERR）
- 可扩展的寄存器映射
- 低延迟设计

## 接口信号
### 全局信号
- `ACLK` - 全局时钟
- `ARESETn` - 全局复位（低有效）

### 读地址通道
- `ARADDR[31:0]` - 读地址
- `ARVALID` - 读地址有效
- `ARREADY` - 读地址就绪

### 读数据通道
- `RDATA[31:0]` - 读数据
- `RVALID` - 读数据有效
- `RREADY` - 读数据就绪
- `RRESP[1:0]` - 读响应

### 写地址通道
- `AWADDR[31:0]` - 写地址
- `AWVALID` - 写地址有效
- `AWREADY` - 写地址就绪

### 写数据通道
- `WDATA[31:0]` - 写数据
- `WVALID` - 写数据有效
- `WREADY` - 写数据就绪
- `WSTRB[3:0]` - 写字节选通

### 写响应通道
- `BVALID` - 写响应有效
- `BREADY` - 写响应就绪
- `BRESP[1:0]` - 写响应

## 典型应用
- 作为显示控制器的总线接口
- 传感器数据寄存器访问
- 系统配置和控制寄存器

## 目录结构
- `rtl/` - RTL 源码
- `tb/` - 测试平台
- `docs/` - 详细文档（如寄存器映射表）
