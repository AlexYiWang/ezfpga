# UART 通信模块

## 功能描述
提供标准的 UART（通用异步收发传输器）通信模块，支持可配置的波特率和简单的 8N1 数据格式（无校验位），用于 FPGA 与 PC 或其他设备的串口通信。

## 特性
- 参数化设计，可配置时钟频率和波特率
- 支持常用波特率：9600, 19200, 38400, 57600, 115200, 230400 等
- 8N1 格式：1 起始位 + 8 数据位 + 1 停止位
- 接收模块采用 3 级同步器，防止亚稳态
- 接收数据在每位中间位置采样，确保数据稳定

## 接口说明

### uart_rx（接收模块）

| 信号 | 方向 | 宽度 | 描述 |
|------|------|------|------|
| clk | 输入 | 1 | 系统时钟 |
| rst_n | 输入 | 1 | 复位信号，低有效 |
| uart_rxd | 输入 | 1 | UART 接收引脚 |
| uart_rx_done | 输出 | 1 | 接收完成脉冲信号 |
| uart_rx_data | 输出 | 8 | 接收到的数据 |

### uart_tx（发送模块）

| 信号 | 方向 | 宽度 | 描述 |
|------|------|------|------|
| clk | 输入 | 1 | 系统时钟 |
| rst_n | 输入 | 1 | 复位信号，低有效 |
| uart_tx_en | 输入 | 1 | 发送使能脉冲 |
| uart_tx_data | 输入 | 8 | 要发送的数据 |
| uart_txd | 输出 | 1 | UART 发送引脚 |
| uart_tx_busy | 输出 | 1 | 发送忙标志 |

## 参数说明

| 参数 | 默认值 | 描述 |
|------|--------|------|
| CLK_FREQ | 50_000_000 | 系统时钟频率（Hz） |
| UART_BPS | 115200 | 目标波特率 |

## 数据帧格式

```
    ┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
    │ 0 │ D0│ D1│ D2│ D3│ D4│ D5│ D6│ D7 │ 1 │
    └───┴───┴───┴───┴───┴───┴───┴───┴───┴───┘
     ↑   ↑   ↑   ↑   ↑   ↑   ↑   ↑   ↑   ↑
    起始 数据位（LSB→MSB）        停止
     位
```

- 空闲电平：高电平
- 起始位：1 位低电平
- 数据位：8 位，LSB 先发
- 停止位：1 位高电平

## 工作原理

### 接收（uart_rx）
1. **同步器**：3 级寄存器链将异步输入同步到时钟域
2. **起始位检测**：检测 rxd 下降沿（空闲时）启动接收
3. **波特率计数**：每位时间计数一次
4. **位计数**：0=起始位，1-8=数据位，9=停止位
5. **数据采样**：在每位中间位置采样数据
6. **完成输出**：停止位中间位置输出完成脉冲和数据

### 发送（uart_tx）
1. **使能锁存**：收到发送使能时锁存数据
2. **波特率计数**：每位时间计数一次
3. **位计数**：0=起始位，1-8=数据位，9=停止位
4. **串行输出**：根据位计数器输出对应位

## 使用示例

```verilog
// UART 回环测试
uart_loopback #(
    .CLK_FREQ (50_000_000),    // 50MHz 系统时钟
    .UART_BPS (115200)         // 115200 波特率
) u_uart_loopback (
    .sys_clk  (sys_clk  ),
    .sys_rst_n(sys_rst_n),
    .uart_rxd (uart_rxd ),
    .uart_txd (uart_txd )
);
```

## 设计备注
- 发送和接收独立工作，可单独使用
- 发送 busy 信号可连接回接收使能实现回环
- 采样点选在每位中间位置，容忍一定的时钟偏差
