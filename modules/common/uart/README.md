# 标准串口调试模块

## 功能描述
提供标准的 UART（通用异步收发传输器）通信模块，支持可配置的波特率、数据位、停止位和校验位，用于 FPGA 与 PC 或其他设备的串口通信。

## 特性
- 完全参数化的 UART 收发器
- 支持常用波特率：9600, 19200, 38400, 57600, 115200, 230400 等
- 可配置数据位：5-9 位
- 可配置停止位：1, 1.5, 2 位
- 可配置校验位：无、奇校验、偶校验
- 内置 FIFO 缓冲区（可选）
- 自动波特率检测（可选）
- 错误检测：帧错误、奇偶校验错误、溢出错误

## 接口说明
### 物理接口
- `uart_tx` - 串口发送线
- `uart_rx` - 串口接收线

### 控制接口
- `clk` - 系统时钟（频率至少为波特率的 16 倍）
- `rst_n` - 复位（低有效）
- `baud_rate` - 波特率选择（参数或动态配置）
- `data_bits` - 数据位配置
- `stop_bits` - 停止位配置
- `parity` - 校验位配置（0: 无, 1: 奇校验, 2: 偶校验）

### 发送接口
- `tx_data` - 发送数据（8 位或可配置宽度）
- `tx_valid` - 发送数据有效
- `tx_ready` - 发送就绪（可接受新数据）
- `tx_busy` - 发送忙标志

### 接收接口
- `rx_data` - 接收数据
- `rx_valid` - 接收数据有效
- `rx_error` - 接收错误（3 位：帧错误、奇偶错误、溢出错误）
- `rx_break` - 检测到 BREAK 条件

### 状态指示
- `tx_active` - 正在发送数据
- `rx_active` - 正在接收数据
- `error_count` - 错误计数器（可清零）

## 波特率生成
使用分频器生成内部采样时钟：
```
分频系数 = 系统时钟频率 / (波特率 × 过采样率)
```
推荐过采样率为 16，提高抗噪能力。

## 数据格式
```
起始位(0) + 数据位(5-9) + 校验位(可选) + 停止位(1/1.5/2)
```
- 起始位：1 位逻辑 0
- 数据位：LSB 先发送
- 停止位：逻辑 1

## 错误处理
### 帧错误
停止位不是逻辑 1，表示帧同步丢失。

### 奇偶校验错误
计算的奇偶位与接收的奇偶位不匹配。

### 溢出错误
接收缓冲区满时收到新数据。

## 使用示例
```verilog
// UART 实例化
uart #(
    .CLK_FREQ(50_000_000),    // 50MHz 系统时钟
    .BAUD_RATE(115200),       // 波特率
    .DATA_BITS(8),            // 8 位数据
    .STOP_BITS(1),            // 1 位停止位
    .PARITY("NONE"),          // 无校验
    .FIFO_DEPTH(16)           // FIFO 深度
) u_uart (
    .clk(sys_clk),
    .rst_n(sys_rst_n),
    .uart_tx(uart_tx),
    .uart_rx(uart_rx),
    .tx_data(tx_data),
    .tx_valid(tx_valid),
    .tx_ready(tx_ready),
    .rx_data(rx_data),
    .rx_valid(rx_valid),
    .rx_error(rx_error)
);
```

## 目录结构

  - `uart_rx.sv` - 接收器
  - `uart_top.sv` - 顶层模块
  - `baud_generator.sv` - 波特率生成器
- `tb/` - 测试平台
- `docs/` - 时序图和协议说明
- `examples/` - 应用示例（如串口回环、命令解析）
