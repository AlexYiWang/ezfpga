# HC-05 蓝牙模块 UART 透明传输驱动

## 功能描述
提供 HC-05 蓝牙模块的 FPGA 驱动，支持 UART 串口通信，实现无线数据传输功能。

## 特性
- 标准 UART 协议（可配置波特率）
- 支持 HC-05 的 AT 命令模式和数据模式
- 自动波特率检测（可选）
- 数据缓冲和流控制
- 错误检测和重传机制
- 多设备连接管理（主/从模式）

## 接口说明
### UART 物理接口
- `uart_tx` - UART 发送线（到 HC-05 的 RXD）
- `uart_rx` - UART 接收线（来自 HC-05 的 TXD）

### 控制接口
- `mode` - 工作模式（0: 数据模式, 1: AT 命令模式）
- `baud_rate` - 波特率选择（9600, 19200, 38400, 57600, 115200）
- `reset_n` - 模块复位（低有效）
- `en` - 模块使能

### 数据接口
- `tx_data` - 发送数据（8 位）
- `tx_valid` - 发送数据有效
- `tx_ready` - 发送就绪
- `rx_data` - 接收数据（8 位）
- `rx_valid` - 接收数据有效
- `rx_error` - 接收错误（奇偶校验、帧错误）

### 状态指示
- `connected` - 蓝牙连接状态
- `pairing` - 配对状态
- `error` - 错误状态

## HC-05 AT 命令集
| 命令 | 功能 | 响应 |
|------|------|------|
| AT | 测试连接 | OK |
| AT+NAME? | 查询模块名称 | +NAME:<name> |
| AT+NAME=<name> | 设置模块名称 | OK |
| AT+PSWD? | 查询配对密码 | +PSWD:<pwd> |
| AT+PSWD=<pwd> | 设置配对密码 | OK |
| AT+UART? | 查询串口参数 | +UART=<baud>,<stop>,<parity> |
| AT+ROLE? | 查询角色（0: 从机, 1: 主机） | +ROLE:<role> |
| AT+RESET | 软件复位 | OK |

## 工作流程
### 初始化阶段
1. 进入 AT 命令模式（KEY 引脚拉高）
2. 配置模块参数（名称、密码、角色、波特率）
3. 返回数据模式（KEY 引脚拉低）

### 数据透明传输
1. 等待蓝牙连接（`connected` 信号变高）
2. 接收数据：UART 数据存入接收缓冲区
3. 发送数据：从发送缓冲区读取并通过 UART 发送
4. 处理连接断开和重连

## 波特率配置
HC-05 支持多种波特率，常用配置：
- 9600（默认）
- 19200
- 38400
- 57600
- 115200（推荐）

## 目录结构
- `rtl/` - RTL 源码

  - `hc05_controller.sv` - HC-05 控制器
  - `at_command_parser.sv` - AT 命令解析器
  - `data_fifo.sv` - 数据缓冲 FIFO
- `tb/` - 测试平台
- `docs/` - HC-05 数据手册和接线图
- `examples/` - 应用示例
