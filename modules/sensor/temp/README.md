# Temperature Sensor Module

This module contains RTL and testbench for temperature sensor interface.

## Directory Structure

- `rtl/` - RTL source files for temperature sensor interface
- `tb/` - Testbench files for simulation and verification

## Overview

This module provides FPGA-based interface logic to read data from temperature sensors.

## Features

- Digital temperature measurement
- Configurable sampling rate
- Error detection and handling

## Usage

Place RTL files in the `rtl/` directory and testbench files in the `tb/` directory.
