# MPU6050 陀螺仪/加速度计 I2C 驱动

## 功能描述
提供 MPU6050 六轴运动处理传感器的 FPGA 驱动，通过 I2C 接口读取加速度计、陀螺仪和温度数据。

## 特性
- 完整的 I2C 主机控制器
- 支持标准速度（100kHz）和快速模式（400kHz）
- 自动初始化 MPU6050 寄存器
- 数据读取轮询或中断模式
- 数字运动处理器（DMP）支持（可选）
- 校准和数据滤波功能

## 接口说明
### I2C 物理接口
- `scl` - I2C 时钟线（开漏，需上拉）
- `sda` - I2C 数据线（开漏，需上拉）

### 控制接口
- `start` - 启动数据读取
- `done` - 读取完成标志
- `mode` - 工作模式（初始化、校准、读取）

### 数据输出接口
- `accel_x`, `accel_y`, `accel_z` - 三轴加速度（16 位有符号）
- `gyro_x`, `gyro_y`, `gyro_z` - 三轴角速度（16 位有符号）
- `temperature` - 温度数据（16 位有符号）
- `data_valid` - 数据有效标志

### 配置接口
- `i2c_addr` - MPU6050 I2C 地址（默认 0x68/0x69）
- `sample_rate` - 采样率配置
- `accel_range` - 加速度计量程（±2g/±4g/±8g/±16g）
- `gyro_range` - 陀螺仪量程（±250/±500/±1000/±2000 °/s）

## MPU6050 关键寄存器
| 寄存器地址 | 名称 | 功能 |
|------------|------|------|
| 0x6B | PWR_MGMT_1 | 电源管理 |
| 0x1B | GYRO_CONFIG | 陀螺仪配置 |
| 0x1C | ACCEL_CONFIG | 加速度计配置 |
| 0x19 | SMPLRT_DIV | 采样率分频器 |
| 0x3B | ACCEL_XOUT_H | 加速度计 X 轴高字节 |
| 0x43 | GYRO_XOUT_H | 陀螺仪 X 轴高字节 |
| 0x41 | TEMP_OUT_H | 温度高字节 |

## 工作流程
1. **初始化阶段**
   - 发送唤醒命令（PWR_MGMT_1）
   - 配置量程和采样率
   - 可选：启用 DMP

2. **数据读取阶段**
   - 发送读取命令（起始地址 0x3B）
   - 连续读取 14 字节（加速度、温度、陀螺仪）
   - 解析数据并输出

3. **校准阶段**（可选）
   - 采集静止状态数据
   - 计算零偏补偿值
   - 存储到非易失性存储器
