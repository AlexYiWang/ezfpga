# ezfpga 🚀

Welcome to **ezfpga**! 

The goal of this repository is simple: to make FPGA development **easy, fun, and accessible**. 

Whether you are hacking on a new development board, trying to light up a display, reading sensor data, or just looking for inspiration for your next hardware build, you will find useful and ready-to-use "bricks" here.

## 🛠️ What's Inside?

This repository is continuously updated with:
* **Plug-and-Play Drivers:** Reusable RTL code (Verilog/SystemVerilog) for various physical modules, sensors, displays, and common peripherals.
* **Fun Project Collections:** Creative and interesting FPGA side projects that go beyond the boring blinking LEDs.
* **Dev Board Hacks:** Practical examples tailored for popular FPGA development boards.
